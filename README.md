# DSA Exercises in Java

Each `.java` file is an independent console program translated from a C++ exercise in the original Algo repository. The algorithms and expected input/output formats are retained.

Compile all programs from this directory:

```sh
javac *.java
```

Run one program by its class name, for example:

```sh
java ThreeNPlusOneProblem
```

Input is read from standard input. Class names use PascalCase versions of the original exercise filenames; `3n_plus_1_problem.cpp` is `ThreeNPlusOneProblem.java`.
